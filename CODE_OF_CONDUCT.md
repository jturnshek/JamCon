# Code of Conduct

JamCon is an open source community. We want a welcoming, respectful, and
productive environment for everyone.

## Expectations

- Be respectful and constructive.
- Assume good intent and be considerate.
- Use welcoming, inclusive language.
- Respect privacy and confidentiality.

## Unacceptable behavior

- Harassment, discrimination, or hate speech.
- Sexualized language or imagery.
- Trolling, spamming, or personal attacks.
- Publishing someone else's private information.

## Enforcement

Project maintainers may edit or remove content, and may restrict participation to
maintain a safe community.

## Reporting

Report violations by opening an issue. If you are not comfortable reporting
publicly, use GitHub's "Report content" feature on the relevant thread and note
that it is a code of conduct concern.
